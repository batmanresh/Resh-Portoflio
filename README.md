# Resham Gurung — Portfolio

## Run locally
1. Install Node.js (LTS).
2. Open this project folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev` and open the local URL printed by Vite.
5. Run `npm run build` before deployment.

## Admin editor
Open `/admin` to access the content editor. Sign in with `batmanresh007@gmail.com` and `admin123`. You can change the password in the Profile tab. Password recovery is not included. Content is stored in the current browser's `localStorage`; edits are not shared with visitors or other devices.

## Before publishing
- Verify all performance figures and add context where necessary.
- Add your LinkedIn URL and hosted CV link in the admin editor.
- Replace example project image URLs with approved Asteria/event/campaign assets.
- Review project descriptions and only publish details you are allowed to share.
- Configure a persistent shared content store if you need edits to appear for all visitors/devices.
